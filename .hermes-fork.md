# Hermes Orchestrator (Agent Orchestrator+)

Merge-friendly fork of [OrchestratorInc/agent-orchestrator](https://github.com/OrchestratorInc/agent-orchestrator).

## Fork contract
- `main` **must always match upstream** `main` exactly. Never commit to it directly.
- All custom work lives on `plus/main` (and `plus/*` feature branches) and is **additive**: new packages/dirs/routes wherever possible; minimal edits to existing upstream files.
- Upstream merges: `git fetch upstream && git switch plus/main && git merge upstream/main`. Conflicts should be rare and shallow because the plus layer avoids touching upstream files.
- Upstream push is disabled on the `upstream` remote on purpose.

## The "+" layer (Hermes dashboard)
Hermes-first dashboard + orchestration on top of Agent Orchestrator. AO already ships a `hermes` agent adapter; the plus layer builds the Hermes-centric UX around it. Nothing upstream is removed — other adapters stay available but the dashboard defaults to Hermes.
